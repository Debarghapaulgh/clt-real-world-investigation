# Central Limit Theorem (CLT) Real-World Investigation

An empirical investigation of the Central Limit Theorem using multiple real-world datasets, examining sampling distributions, convergence to normality, standard error, statistical inference and the limitations of CLT assumptions.

## Project Structure

```text
├── data/
│   ├── raw/            # Original raw datasets (untracked)
│   └── processed/      # Cleaned and processed data for analysis
├── notebooks/          # Exploratory and analytical Jupyter notebooks
├── src/                # Reusable source code and analysis modules
├── reports/            # Analysis outputs and documentation
│   └── figures/        # Generated plots and visualization figures
├── README.md           # Project overview and description
├── requirements.txt    # Project dependencies
└── .gitignore          # Git exclusion rules
```
